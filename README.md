LOCAL DEVELOPMENT
================================================================

1. Clone the repository:
   git clone https://github.com/Mosdefinitely00/muhammad-yunas-portfolio.git

2. Navigate into the project directory:
   cd muhammad-yunas-portfolio

3. Open in VS Code:
   code .

4. Optional: run a local server:
   python -m http.server 8000
   or
   npx serve

5. Open your browser:
   http://localhost:8000

================================================================
GITHUB PAGES DEPLOYMENT
================================================================

1. Stage and commit changes:
   git add .
   git commit -m "Update portfolio"

2. Push to main:
   git push origin main

3. Enable GitHub Pages:
   - Open repository settings
   - Select Pages
   - Choose branch: main
   - Choose folder: root

4. Wait for deployment to complete.

5. Access the live site:
   https://mosdefinitely00.github.io/muhammad-yunas-portfolio/
