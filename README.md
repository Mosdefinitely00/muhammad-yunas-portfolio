LOCAL DEVELOPMENT
================================================================

Clone the repository:  
    git clone https://github.com/Mosdefinitely00/muhammad-yunas-portfolio.git

Navigate into the project directory:  
    cd muhammad-yunas-portfolio

Open in VS Code:  
    code .

Optional: run a local server:  
    python -m http.server 8000  
    or  
    npx serve

Open your browser:  
    http://localhost:8000

================================================================
GITHUB PAGES DEPLOYMENT
================================================================

Stage and commit changes:  
    git add .  
    git commit -m "Update portfolio"

Push to main:  
    git push origin main

Enable GitHub Pages:
- Open repository settings  
- Select Pages  
- Choose branch: main  
- Choose folder: root  

Wait for deployment to complete.

Access the live site:  
https://mosdefinitely00.github.io/muhammad-yunas-portfolio/
